# UI quality checklist
- Consistent spacing, type scale, and a small color palette with a dark mode if it fits.
- Responsive from phone to desktop; test at 360px width.
- Every interactive element: hover, focus, disabled, loading states. Visible keyboard focus.
- Accessibility: semantic HTML, labels on inputs, alt text, sufficient color contrast, works with keyboard only.
- Empty states and error messages that tell the user what to do next.
- Fast: optimize images, avoid layout shift, lazy-load heavy parts.
- No lorem ipsum, placeholder images, or fake data in the final product.
